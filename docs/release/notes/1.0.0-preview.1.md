## Toren IDE 1.0.0-preview.1

First downloadable release candidate for Windows, Linux and macOS. This release is a **Draft** for maintainer validation; public publication is pending Apple signing/notarization and the final cross-platform release checklist.

### Included packages

| Platform | Archive | Start |
| --- | --- | --- |
| Windows x64 | `Toren-IDE-win-x64.zip` | Extract all files, then run `Toren.App.exe` |
| Linux x64 | `Toren-IDE-linux-x64.tar.gz` | Extract all files, then run `./Toren.App` |
| macOS Apple Silicon | `Toren-IDE-osx-arm64.zip` | Extract `Toren IDE.app` |
| macOS Intel | `Toren-IDE-osx-x64.zip` | Extract `Toren IDE.app` |

Every archive includes the .NET 10 runtime, Toren's application icon, license, launch instructions and release identity. A separate .NET runtime installation is not needed to launch Toren. Install the SDK required by your projects for restore/build/run; Git is required for source-control features. Linux desktop/native dependencies still apply.

SHA-256 sidecars and `Toren-IDE-release-manifest.json` accompany the four archives. The manifest remains candidate metadata with `distributionReady=false`.

### Highlights

- Refined dark/light palettes, rounded controls, aligned dialogs and responsive tool panels.
- Toren application icon and logo in the title bar, Welcome and About.
- Settings and NuGet Packages in dedicated dialogs; Source Control, Debug, HTTP and other tools in the sidebar.
- Build, Rebuild and Clean controls, build activity feedback, diagnostic navigation and refreshed Problems behavior.
- Terminal starts when its tab opens and supports stopping its process.
- C# navigation/completion, test workflows, Git, ASP.NET Core, HTTP, EF Core and Docker Compose tools.
- A shared four-process budget for background MSBuild evaluations to bound resource use in large workspaces.

### Validation and remaining gates

Cross-platform CI runs source builds, automated tests and release contract checks. Packaging additionally checks version metadata, archive checksums, executable presence and the bundled self-contained runtime.

The previous macOS source-build review covered native interactions plus 249 headless dark/light UI captures. Those checks are useful development evidence, and do not replace hands-on testing of these exact release archives on Windows, Linux and both Mac architectures.

**macOS candidate bundles are not Developer ID signed or notarized.** Do not publish this draft as a public release. Produce both signed macOS artifacts, complete the promoted-asset smoke/visual/accessibility/performance checks, and use the guarded Publish Release workflow before public distribution.

Large solutions remain a known performance limitation: the 220-project Orchard Core graph took about 114 seconds in one service measurement, and native runnable-project preparation still took several minutes. Full Orchard build/run and Windows/Linux performance were not validated in that review. See `docs/design/performance-review.md` for the measurements and their limits.

No installer or automatic updater is included in this candidate.
