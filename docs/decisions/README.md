# Architecture Decision Records

Toren uses Architecture Decision Records (ADRs) for decisions that materially affect product architecture, interoperability, security, platform support, or contributor expectations.

## Status values

- **Proposed** — under discussion.
- **Accepted** — current project direction.
- **Superseded** — replaced by a newer ADR.
- **Rejected** — considered and not adopted.
