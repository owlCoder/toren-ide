# ADR-0006: Apache License 2.0

Status: **Accepted**

## Context

Toren is intended to be a serious open-source developer tool that can be adopted by individuals, educational institutions, and companies. The project should use a permissive license while providing an explicit patent grant.

## Decision

Toren IDE is licensed under the Apache License 2.0.

New dependencies and redistributed components must be reviewed for compatibility with Toren's licensing and distribution model.

## Consequences

- Commercial and non-commercial use, modification, and redistribution are permitted under the license terms.
- Contributors and distributors must comply with Apache-2.0 notice and attribution requirements where applicable.
- Dependency licensing becomes part of normal review for new third-party components.
